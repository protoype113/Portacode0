# CSE Capstone Project Template

We will use this project as the basis for the in class exercises during the first two weeks of Senior Design, Fall 2065.  This is a simple html project with site.js to load cards to the main page.  These cards will provide navigation to each teams solution.

### PROJECT SCOPE:
Here's a link to the [Project Scope](https://docs.google.com/document/d/1KqDA7Xf2RXiFIQnWK0we7l2Rw-PQOdcNUGYXTXoEV4U/edit?usp=sharing).  It includes an explanation for the work and some constraints.

### PROJECT DETAILS:
The website includes:
* Team Information – The team’s name and members are displayed at the top of the page.
* Voting Buttons – Color-coded buttons allow users to vote for the projects they want to participate in.
* Live Chart Updates – A chart dynamically updates in real time to reflect the current voting results.
* Vote Table – A table alongside the chart provides a detailed breakdown of vote counts.
 
#### Visual Studio Code
Using VSC, clone the project using the Source Control features.  To run the app as is, select <code>index.html</code> and select run and debug (Ctrl+Shift+D) on the Activity Bar.

#### As a group:
**Objective:** each team member is meant to contribute to the project for each deliverable.  This is to practice planning work, distributing it, and then pulling it all back together for demonstation.

* As a group, create the team branch.
* As a group, plan the distribution of work across all team members.  Create a GitLab issue for each person to demonstrate use of the planning and development features in GitLab.  [I will be looking for commits and merge requests by student]
* Individually, create the branch and merge request for your assigned issue.
* Complete the assigned work.  Commit and push regularly to the remote repo.
* At the end of each milestone (outlined in the Project Scope document), merge each team members work back into the team branch.  Do a quality check of all the merged code.
* If the team's work is approved, merge it back into the master branch for the instructors review.
